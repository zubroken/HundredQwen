# HundredQwen 系统开发说明书

## 架构

系统保留 FastAPI + 内嵌 SPA + SQLite + JSON 资源库结构。P0 新增 `ResourceGenerationService` 作为资源包主入口，统一调度 Agent、引用、安全、路径和持久化。

## 主流程

1. 前端提交学生、课程、主题、难度和五类资源类型。
2. 服务读取学生画像。
3. `ContentSafetyService` 检查输入。
4. `KnowledgeBase.retrieve()` 检索教材与知识库 chunk。
5. `CitationService` 从真实 chunk 构造引用。
6. 调用 Document、MindMap、Exercise、Reading、CodeExample 五类 Agent。
7. 单个 Agent 失败时生成本地知识库 fallback 资源并标记 `fallback=true`。
8. `LearningPathAgent` 生成路径。
9. `ResourceDB` 保存资源、路径和资源包。
10. 仪表盘刷新后通过 API 重新读取资源包和路径。

## 新增 API

- `POST /api/generation/resource-bundle`
- `GET /api/generation/resource-bundles/{student_id}`
- `GET /api/generation/learning-path/{student_id}`
- `PUT /api/generation/learning-path/{path_id}/nodes/{node_id}`

## 数据模型

`resources.json` 保留旧字段 `resources`、`learning_paths`，新增兼容字段 `resource_bundles`。旧资源接口在无引用时不输出新增字段，避免破坏历史响应。

## 前端

仪表盘保留原卡片布局，在下方新增学习工作台：主题输入、四阶段状态、五类资源卡、引用列表、路径节点和完成按钮。
