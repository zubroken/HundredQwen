# HundredQwen 部署运行说明

## 环境

- Python 3.12 测试通过
- 依赖见 `requirements.txt`
- 默认服务地址：`http://127.0.0.1:9010`

## 启动

```powershell
.\start.ps1
```

启动脚本会复用 9010 端口上已有的 HundredQwen 服务，避免重复开随机端口。

## 重启规则

修改 Python 后端、路由、服务层或页面内嵌 HTML 后，需要重启服务才会加载新代码。当前约定是：项目有新改动且需要后端重载时，由 Codex 自动停止旧 HundredQwen Python 进程并重新执行 `start.ps1`。

## 关键检查

```powershell
python check_server.py
Invoke-WebRequest http://127.0.0.1:9010/api/knowledge/stats
Invoke-WebRequest http://127.0.0.1:9010/api/generation/resource-bundles/stu_001
```

## 无模型降级

真实模型不可用时，资源生成服务会使用本地知识库 chunk 构造 fallback 资源，保留引用和 warning，不伪造来源。
