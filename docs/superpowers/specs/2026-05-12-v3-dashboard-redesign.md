# 百问即查 3.0 — 仪表盘改版设计

## 概述

本版本对百问即查进行 UI 和功能大改版：
- 免登录直接进入仪表盘首页
- 新增侧边栏导航，取代旧版顶部栏+话题选择器
- 新增智能问答（纯文本 LLM 对话，不生成资源）
- 新增做练习题交互式流程（题型→个数→课程→逐题作答）
- 课程文档和学习路径预留占位
- 注释注册功能，移除旧版多智能体全资源生成的前端入口

## 三、头像功能

### 实现方案
预设头像选择：提供 8 个彩色渐变圆形头像，用户点击右上角头像 → 进入个人信息弹窗 → 点击头像 → 弹出头像选择器（网格展示 8 个头像） → 点击选择 → 保存到数据库。

### 数据库改动
`students` 表新增 `avatar` 字段（TEXT，存头像编号 `"avatar-1"` ~ `"avatar-8"`，默认 `"avatar-1"`）。`database.py` 中 `update_profile` 的 allowed 字段加入 `"avatar"`。

### 头像样式
8 个预设头像使用 CSS 渐变 + emoji，不依赖外部图片文件：
- avatar-1: 紫色渐变 + 📚
- avatar-2: 蓝色渐变 + 💻
- avatar-3: 绿色渐变 + 🧠
- avatar-4: 橙色渐变 + 🚀
- avatar-5: 粉色渐变 + ✨
- avatar-6: 青色渐变 + 🎯
- avatar-7: 红色渐变 + 🔥
- avatar-8: 靛蓝渐变 + ⚡

## 四、智能问答（新功能）

### 路由
新增 `POST /api/chat-simple`

### 请求/响应
```
请求: { "student_id": "stu_001", "message": "什么是动态规划？" }
响应: { "reply": "动态规划是..." }
```

### 逻辑
- 直接调用 LLMService.chat()，**不经过 Orchestrator**
- 带上学生画像作为 system prompt 上下文
- System prompt 约束：只能文本问答，不生成文档/图片/资源
- 支持：知识问答、文本总结、代码分析、写简单程序
- 前端：纯聊天界面，消息气泡 + 输入框 + 发送按钮

### 前端
右侧主内容区切换为聊天面板，消息列表 + 底部输入区。

## 五、做练习题（新功能）

### 交互流程（同一面板内状态切换）

```
Step 1 — 选择题型
    [选择题] [填空题] [简答题]

Step 2 — 输入出题个数
    [  5  ]  （数字输入框，默认5，范围1-20）

Step 3 — 选择课程
    系统根据学生画像自动匹配3个关联课程
    [人工智能] [Python编程] [数据结构]

Step 4 — 点击 [开始答题]

Step 5 — 逐题作答
    一题一屏，用户选择/填写作答后点 [下一题]
    顶部显示进度 "第 2/5 题"

Step 6 — 结果页
    显示得分（如 3/5 ✅）
    展开每题解析（答案 + 解释）
    [再做一组] 按钮回到 Step 1
```

### 后端
- 调用已有 `ExerciseAgent`，精确路由限制只生成 exercise
- 新端点（或扩展现有 generate）：`POST /api/exercise/generate`
  - 接收：`{ student_id, question_type, count, course_name }`
  - 返回：`{ questions: [...] }`（不带答案） + `{ answers: [...] }`（答题后请求批改时用）
- 批改在前端做：生成时已带答案，前端在用户提交后展示
