# HundredQwen 需求分析说明书

## 目标用户

面向人工智能相关专业学生，尤其是已经具备 Python、数学与基础机器学习能力，但在深度学习、Transformer、强化学习等高密度知识点上需要结构化辅导的学习者。

## 核心痛点

- 学习资源分散，教材、论文、代码和练习之间缺少关联。
- 学生画像没有真正驱动资源推荐与学习路径。
- 生成内容需要可追溯依据，不能只给无来源回答。
- 比赛演示需要稳定闭环，不能依赖单一外部模型是否可用。

## P0 功能映射

- 学生画像：保留 6 维以上画像字段，包括基础、认知风格、薄弱点、目标、节奏、兴趣、资源偏好、编程经验。
- 五类资源：讲解文档、思维导图、练习题、拓展阅读、代码案例。
- 个性化路径：基于画像、资源与知识库引用生成有顺序的学习路径。
- 安全与引用：输入输出安全检查，引用只来自真实知识库 chunk。
- 学习反馈：路径节点可标记完成，仪表盘展示本周学习时间。
- 降级策略：模型不可用时使用本地知识库生成 fallback 资源，不伪造引用。

## P0 不包含

正式多租户权限、生产级审计、云端部署、异步任务队列、真实视频生成平台。
